# War Thunder — Old Build Downloader

Небольшое графическое приложение (Python + Tkinter, без сторонних библиотек), чтобы
скачивать **старые версии War Thunder из Steam по manifest id**.

Вместо ручного редактирования `.bat` вы указываете ID версии со SteamDB, а приложение
само открывает нужную страницу, запоминает список версий и запускает скачивание.

---

## 1. Запуск

Двойной клик по `run.bat` (или `python wt_old_build.py`).

Требуется Python 3.9+ с модулем `tkinter` (в стандартной Windows-установке он есть).

**Оба инструмента встроены**:

* `tools\DepotDownloader\DepotDownloader.exe` — self-contained, отдельный .NET Runtime не нужен;
* `tools\steamctl\` — steamctl 0.9.5 со всеми зависимостями и совместимой прослойкой
  вместо `gevent` (под Python 3.14). Запускается через `steamctl.cmd`, путь подставляется
  автоматически.

Приложение найдёт оба инструмента само — пути вручную указывать не надо. Можно просто
распаковать архив в любую папку и запустить `run.bat`.
Проверить установку:

```
python wt_old_build.py --selftest
```

Приложение создаст два файла рядом с собой:

* `manifests.json` — ваш каталог «депо + manifest ID + дата + заметка»;
* `settings.json` — папка назначения, выбранный инструмент, потоки и т.д.

## 2. Как получить ID версии со SteamDB (самое важное)

1. В приложении нажмите **«Указать ID версии со SteamDB…»**
   (кнопка есть и в списке манифестов, и справа в настройках загрузки).
2. Приложение **откроет браузер** на странице манифестов выбранного депо, например:

   ```
   https://steamdb.info/depot/236391/manifests/
   ```

3. Если SteamDB попросит вход — войдите в Steam **в самом браузере**.
   Логин, пароль и код Guard идут напрямую на `steamcommunity.com`,
   приложение их не видит, не сохраняет и не запрашивает.
4. Прокрутите страницу вниз до раздела **«Previously seen manifests»**.
   Там колонки `Seen Date` и `ManifestID`.
5. Скопируйте нужную строку целиком **или только число ManifestID**
   (15–20 цифр) и вставьте в поле окна кнопкой **«Вставить из буфера»**.

Поле умное: оно примет и чистый ID, и целую строку из таблицы — дата подставится
автоматически. Если в буфере ссылка вида `steamdb.info/depot/236394/...`,
приложение само переключит депо. Дата **необязательна** и не участвует в загрузке —
это только подпись для сортировки и наглядности.

Сам Manifest ID — просто непрозрачный номер, дата в нём не закодирована. Если вы
вставили только ID и хотите узнать год, нажмите **«Узнать дату по ID»** рядом с полем
даты: приложение запросит у Steam (`steamctl depot info`) поле `Created On` и подставит
его автоматически. Для этого нужен установленный steamctl и выполненный один раз вход
(кнопка «Вход…» справа). Без входа просто оставьте дату пустой — на скачивание это
не влияет.

Если нужно добавить сразу много версий — используйте **«Импорт со SteamDB…»**:
вставьте туда всю таблицу, нажмите «Разобрать», затем «Добавить».
Там же есть кнопка **«Из HTML-файла…»**: можно загрузить сохранённую страницу
`depot/<id>/manifests/` (например, `steamdb.txt`) или HAR-дамп (`steamdb.info.har`) —
приложение само найдёт внутри HTML со списком и вытащит все даты и ID разом.

**Снимок страницы быстро устареет.** Для новых версий используйте живой сценарий:
кнопка «Указать ID версии со SteamDB…» каждый раз открывает актуальную страницу
в браузере, и вы копируете оттуда новую строку/ID. Импорт HTML — это только быстрый
способ один раз затянуть всю историю, а не замена обновлению из браузера.

Ссылки на нужные страницы:

* все депо игры: <https://steamdb.info/app/236390/depots/>
* контент (aces, content): <https://steamdb.info/depot/236391/manifests/>
* launcher / бинарники Windows: <https://steamdb.info/depot/236394/manifests/>
* Linux: <https://steamdb.info/depot/236393/manifests/>
* macOS: <https://steamdb.info/depot/236392/manifests/>

Для сборки **15 августа 2013** уже известен один манифест (он в каталоге по умолчанию):

| Depot | Manifest | Дата | Что это |
|---|---|---|---|
| 236391 | `3264770838696250786` | 2013-08-15 12:13:36 UTC | War Thunder Content (`aces.vromfs.bin`, `content`) |

Для полной сборки того времени дополнительно найдите на SteamDB манифест депо
**236394** (launcher) на ту же дату и добавьте его тем же способом.

## 3. Скачивание

1. В списке слева выделите одну или несколько строк (Ctrl / Shift).
2. Справа проверьте папку назначения (по умолчанию `C:\WT_old`).
3. Выберите инструмент:
   * **DepotDownloader (QR-вход)** — встроенный бинарник из `tools\DepotDownloader`;
     QR-код появится прямо в нижней панели приложения.

   Если во время QR-входа соединение с Steam прервалось (в логе `Failed to poll status
   with result FileNotFound` / `Lost connection`), но сам QR вы успели отсканировать —
   токен уже сохранён. Введите свой логин в поле **«Имя пользователя Steam»**, снимите
   галочку **«QR-вход»** и повторите: приложение запустит `-username ... -remember-password`.
   * **steamctl** — встроенный `tools\steamctl\steamctl.cmd`; кнопка «Вход…» откроет
     консоль для входа. Пароль можно ввести в поле **«Пароль Steam»** — он передаётся
     процессу через `STEAMCTL_PASSWORD`, **не сохраняется на диск** и не попадает в лог.
   Если процесс запросит код Guard/2FA, внизу панели лога есть поле **«Ввод»** (активно
   во время загрузки): введите код и нажмите Enter — он отправится в процесс.
4. Нажмите **«Скачать выбранное»**. Кнопка **«Показать команды»** позволяет заранее
   увидеть точные команды и скопировать их.

Лог пишется в окно и в файл `wt-download-<дата>.log` в папке назначения.
Как и в исходном `.bat`, после завершения создаётся `exit.txt` с кодом возврата
(`0` = успех).

Кнопка **«Остановить всё»** доступна, пока идёт любая операция: загрузка, вход
через «Вход…» или запрос даты по ID. Она завершает процесс(-ы) и все дочерние процессы.

---

## 4. Что где лежит

* `wt_old_build.py` — исходный код приложения;
* `manifests.json` — каталог версий (можно править и вручную);
* `settings.json` — настройки;
* `<папка назначения>/wt-download-*.log` — логи загрузок;
* `<папка назначения>/exit.txt` — код возврата последней задачи.

---

## 5. Про ангар 2013 года

Это приложение только **скачивает файлы нужной версии**. Перенос старого ангара
(`aces.vromfs.bin`, `content`, `char.vromfs.bin` и т.п.) в современный клиент —
отдельная задача моддинга: форматы VROMFS и пути менялись, поэтому файлы нужно
подготовить/запатчить перед копированием в текущую установку. Скачанную старую
копию удобно держать отдельно от основной игры и подключать точечно.

---

## 6. Важно

* Нужен аккаунт Steam с доступом к игре (War Thunder бесплатна, доступ есть у всех).
* Приложение не обходит защиту Steam — оно лишь запускает легальные утилиты с
  корректным manifest id.
* SteamDB иногда требует вход через Steam, чтобы показать *полную* историю
  манифестов — это не ошибка приложения.

Меню **Инструменты → Проверить пути инструментов** покажет, найдены ли
`DepotDownloader.exe` / `steamctl`; пути можно указать вручную кнопкой «Обзор…».
